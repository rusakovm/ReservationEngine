🗓️ ReservationEngine

ReservationEngine — REST API для управления ресурсами и бронированиями, разработанный на Python и FastAPI с использованием PostgreSQL.

Проект реализует создание, редактирование и отмену бронирований, проверку временных конфликтов и работу с конкурентными запросами.








✨ Возможности

📦 Управление ресурсами

Создание, просмотр и редактирование ресурсов

Получение списка активных ресурсов

Мягкое удаление через is_active = False

📅 Управление бронированиями

Создание бронирований с указанием времени

Просмотр бронирований

Изменение временного интервала

Отмена бронирований с сохранением истории

Проверка пересечения активных бронирований

Использование SELECT FOR UPDATE при создании и изменении бронирований

🛡️ Валидация

Проверка корректности временных интервалов

Обязательное указание часового пояса

Обработка HTTP-ошибок 404, 409 и 422

Валидация данных через Pydantic
